Arduino 藍芽遙控車 — 電路設計

雙輪驅動車體 + TB6612FNG 馬達驅動 + HC-05 藍芽模組 + App Inventor，全部共用一組 4×1.5V 電池盒供電（Arduino Uno）。下面先把電路跟接腳定下來，你照著插好麵包板、完成 (a)(b) 兩階段測試沒問題後，我們再進到藍芽跟 App Inventor 的部分。

四個階段

a

馬達正反轉測試

兩顆 TT 馬達各自正轉、反轉，確認 TB6612 接線方向正確。

b

動作邏輯

寫成前進 / 後退 / 左轉 / 右轉函式，車體實際跑跑看。

c

藍芽遙控

接上 HC-05，App Inventor 四個方向按鈕即時控制。

d

漸進加減速

按住加速、放開減速，PWM 隨時間平滑變化。

電源共用注意事項

你選的是「4 顆電池同時供電 Arduino + 馬達」

  • Uno 內建穩壓 IC 建議 Vin 至少 7V 才穩定，6V 已經在邊緣。馬達啟動瞬間電流突增會讓電壓下垂（sag），可能讓 Arduino 重開機——常見症狀是藍芽突然斷線、程式像是「從頭重跑」。
  • 建議在 TB6612 的 VM／GND 腳位附近、麵包板電源軌上，並聯一顆 100～470µF 電解電容，緩衝馬達啟動瞬間的電流尖峰（電容長腳接正極、短腳接負極，別接反）。
  • 盡量用新的鹼性電池。如果之後常常無預警重開機，先換電池排除電力問題；還是不行的話，再考慮把 Arduino 改成 USB 供電、電池只留給馬達。

麵包板組裝建議順序

  1. 先架好電源軌：麵包板正負軌接到電池盒——先不要放電池！
  2. 插上三個模組：Arduino、TB6612FNG、HC-05 都先插上麵包板，只接 GND 跟電源腳位，用電表量一下電池 (+) 跟 GND 之間沒有短路。
  3. 接訊號線：照上面對照表接 D2～D10。
  4. 特別檢查 STBY：確認 D4 有接到 TB6612 的 STBY，這條漏接是最常見的「馬達完全不會轉」原因。
  5. 先不接馬達，通電測試：放電池，Arduino 接電腦跑個簡單的 LED blink，確認開機穩定、不會因為電源不穩重開機。
  6. 最後才接馬達：把左右 TT 馬達接到 AO1/AO2、BO1/BO2，準備進入 (a) 階段的正反轉測試。
